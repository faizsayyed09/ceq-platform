# Archive Plan

Move uncertain historical assets under `archive/` rather than deleting them. Archive candidates:

- Historical presentation PDFs and process-flow exports.
- Legacy architecture/development/development-workflow documents after canonical docs replace them.
- Component and flow inventory text files.
- Duplicate/recovered components and flow exports only after runtime parity.
- Manual deployment accelerators and superseded workflows only after the single deployment path passes parity.
- Phase topic branches only after merge and branch confirmation.

Destructive archive actions require a repository-relative source, destination, runtime reference search, and replacement test result.
